# Security Policy

If you believe you have found a security vulnerability in PiPic — the
website, the API, or the `@pipic/cli` package — please report it
privately. **Do not open a public issue.**

- Email: [contact@pipic.cc](mailto:contact@pipic.cc)
- Machine-readable contact: [security.txt](https://pipic.cc/.well-known/security.txt)

We aim to acknowledge reports within a few business days. Please include
enough detail to reproduce the issue; proof-of-concept over live user
data is never necessary.
